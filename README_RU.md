# Applux — стартовый Telegram Mini App

Это демонстрационный фронтенд каталога: поиск, категории, карточки приложений и корзина.
Ссылки ведут на официальные страницы App Store. Оплата, сервер, база данных, Telegram WebApp SDK и отправка заказов пока не подключены.

## Самый простой путь запуска только с iPhone

1. Открой GitHub в Safari: https://github.com/ и создай аккаунт, если его ещё нет.
2. Создай новый репозиторий с названием `applux-mini-app` (Public).
3. Загрузи содержимое архива в репозиторий. На GitHub для iPhone можно открыть `Add file` → `Upload files`, выбрать файлы и папки из приложения «Файлы». Если загрузка папок неудобна, распакуй ZIP в приложении «Файлы» и добавляй файлы по отдельности, сохраняя структуру.
4. Создай аккаунт на https://vercel.com/ и подключи GitHub.
5. Импортируй репозиторий `applux-mini-app`, оставь настройки Vite по умолчанию и нажми Deploy.
6. После публикации скопируй URL вида `https://...vercel.app`.
7. В BotFather открой `/mybots` → `@Applux63_bot` → `Bot Settings` → `Menu Button` (названия пунктов могут меняться), укажи URL опубликованного сайта и текст кнопки, например `Открыть Applux`.
8. Открой своего бота и проверь кнопку.

## Важно
- Никогда не публикуй токен Telegram-бота в репозитории, браузере или переписке.
- Если старый токен ранее был раскрыт, отзови его и создай новый через BotFather.
- На старте корзина хранится только в состоянии страницы и не отправляет заказ.
- Перед публичным запуском проверь доступность приложений в регионе пользователей и добавь описание, политику конфиденциальности и контакт поддержки.
